# Current KOTMA-SR Result Package

This folder contains the current retrospective KOTMA-SR outputs generated for the manuscript.

Key contents:

- `figures_kbs/`: manuscript figure files and source data.
- `supplementary_figures/`: supplementary figure files and source data.
- `shared/`: primary benchmark, calibration, robustness, and audit tables shared across figures.
- `audits/`: execution and claim-readiness checks.
- `shared/dataset_scope_summary.csv`: anonymized dataset-scope summary for manuscript reporting.
- `shared/method_rule_table.csv`: reproducibility table for descriptor retrieval, structural memory, FGW matching, sparse-tail correction, intervals, and review triggers.
- `shared/example_recommendation_card.csv`: one held-out recommendation-card example exported from the grouped validation traces.
- `shared/protocol_mapping_audit.csv`: mapping between manuscript tables/figures and their experimental protocol families.
- `AEI_SUPPORT_AUDIT.md`: reviewer-facing audit of the added Advanced Engineering Informatics support material.
- `KOTMA-SR_Fig1-9_Editable_Visio.vsdx`: editable Visio figure package for manuscript refinement.
- `RUN_MANIFEST.json`: execution manifest for the result package.
- `MANUSCRIPT_READINESS_REPORT.md`: result-level readiness summary.

The uploaded result package excludes the raw enterprise database. It is intended to document the current computed outputs and support manuscript review, not to disclose sensitive production records.
